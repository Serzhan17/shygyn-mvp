# Shygyn — финансовый помощник (рабочий MVP)

React + Vite, Django REST Framework, локальная SQLite (или PostgreSQL по настройке).
Тёмно-зелёный интерфейс основан на идее и визуальном стиле презентации **Shygyn Pitch Deck**.

## Что работает

- Регистрация, вход, выход; пароли хранятся как хеши Django.
- Изолированные по пользователям счета (карта и наличные).
- CRUD операций (доходы, расходы, категории, дата, описание, счёт).
- Месячный лимит; остаток = **бюджет − расходы за месяц**.
- Общее состояние счетов = начальные остатки + доходы − расходы.
- Аналитика за выбранный месяц: динамика, категории, диаграммы.
- Поиск и фильтрация операций, выгрузка CSV для выбранного месяца.
- Калькулятор аннуитетных кредитов (ипотека, авто, бизнес) и сравнение трёх **условных** ставок.
- Адаптивный интерфейс, PWA-манифест для добавления на главный экран (без офлайн-кеша).
- Демонстрационные данные для локального тестирования и API-тесты.

**Не работает пока:** автоматическая синхронизация с Kaspi/Halyk/другими банками, получение настоящих ставок, банковские заявки, ГЭСВ, автоматический импорт выписок, корпоративные кабинеты, облачная инфраструктура. Эти функции требуют отдельных интеграций и согласований.

## Требования

- Python 3.10+ (для Django 5.2), Node.js 20.19+ или 22+ с npm.
- Интернет при первоначальной установке зависимостей.

## 1. Запуск Backend (Windows PowerShell)

Откройте PowerShell в папке `Shygyn_MVP`:

```powershell
cd backend
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 127.0.0.1:8000
```

Если PowerShell запрещает активацию окружения, вместо неё можно использовать `.venv\Scripts\python.exe` для вызовов Python и `.venv\Scripts\pip.exe` для pip.

Backend API: http://127.0.0.1:8000/api/health/

### Linux / macOS

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 127.0.0.1:8000
```

## 2. Запуск Frontend (в новом терминале)

```bash
cd frontend
npm install
npm run dev
```

Открыть в браузере: **http://127.0.0.1:5173**.

**Демо-вход:** `demo@shygyn.kz` / `ShygynDemo2026!` — данные создаются командой `seed_demo` и предназначены исключительно для локального тестирования. Можно также зарегистрировать свой тестовый аккаунт.

## API endpoints

| Method | Path | Описание |
|---|---|---|
| POST | `/api/auth/register/` | Регистрация |
| POST | `/api/auth/login/` | Вход |
| GET | `/api/auth/me/` | Профиль |
| POST | `/api/auth/logout/` | Выход и удаление токена |
| GET, POST | `/api/accounts/` | Счета |
| GET, PATCH, DELETE | `/api/accounts/{id}/` | Операции со счётом |
| GET, POST | `/api/transactions/` | Доходы и расходы (фильтр `?month=YYYY-MM`) |
| GET, PATCH, DELETE | `/api/transactions/{id}/` | Операции с записью |
| GET, POST | `/api/budgets/` | Бюджеты, POST обновляет лимит месяца |
| GET | `/api/summary/?month=2026-10` | Сводка бюджета, категории, динамика |
| GET | `/api/categories/` | Список категорий |
| GET | `/api/loans/compare/?kind=auto&amount=5000000&months=60` | Учебные ставки и платежи |
| GET | `/api/health/` | Проверка доступности |

Авторизация для защищённых запросов: заголовок `Authorization: Token <token>`.

## Тесты и production build

```bash
cd backend
python manage.py test
python manage.py check
```

```bash
cd frontend
npm run build
```

Готовая сборка будет в `frontend/dist/`. Backend и frontend требуют отдельного размещения на сервере. Для удалённого API используйте `VITE_API_BASE_URL` перед сборкой.

## PostgreSQL вместо SQLite

В `backend/.env.example` есть перечень настроек. Django считывает **переменные окружения**, а не `.env` автоматически. Установите `DATABASE_ENGINE=postgresql`, переменные `POSTGRES_*` и пакет `psycopg[binary]` отдельно. Затем выполните `python manage.py migrate`.

## Безопасность и реальные деньги

Это прототип для локального использования и презентаций, **не прошедший финтех-аудит**.
Не вводите настоящие номера карт, CVV, пароли банков или конфиденциальные финансовые выписки. Для настоящих пользователей и деплоя нужны как минимум: HTTPS, секреты только в окружении, безопасные cookies и защита от CSRF, истекающие/отзываемые токены, многофакторная аутентификация, ограничение попыток входа, мониторинг, резервирование, политика конфиденциальности, проверка требований законодательства Казахстана и аудит безопасности. В MVP токен хранится в `localStorage`; это **не рекомендуется для production**. Используйте защищённую инфраструктуру и проверенные банковские интеграции после соответствующих разрешений.

Сравнение кредитов показывает только иллюстративные номинальные ставки. Реальная **ГЭСВ** зависит от дополнительных затрат и не рассчитывается этим калькулятором.

### Ещё проще: запуск на Windows в два клика

После установки Python и Node.js откройте два файла (каждый в своём окне):
1. `start_backend_windows.bat` — устанавливает Python-зависимости, создаёт БД и тестовые данные, запускает API.
2. `start_frontend_windows.bat` — устанавливает npm-зависимости и запускает интерфейс.

При первом запуске необходим интернет. Повторный запуск использует уже скачанные зависимости.
